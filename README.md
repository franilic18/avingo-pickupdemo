# AVINGO Rent a Car

Mobilni frontend prototip za digitalno preuzimanje i vraćanje vozila.

## GitHub Pages
1. Kreiraj novi GitHub repository.
2. Uploadaj `index.html`, `style.css` i `script.js`.
3. Settings → Pages.
4. Deploy from branch → `main` → `/root`.
5. Save.
6. GitHub će dati javni link.

Ovo je demo frontend; za produkciju treba backend, baza, stvarni upload fotografija, autentifikacija, QR generator i administratorski panel.
